# Customer Churn Analysis

This project aims to analyze customer churn and build a predictive model to identify customers at risk of leaving.

## Project Structure

```
Customer-Churn-Analysis/
│
├── data/
│   ├── cleaned_churn_data.csv
│   └── final_fixed_data.csv
│
├── notebooks/
│   └── churn_analysis.ipynb
│
├── outputs/
│   ├── churn_eda.png
│   ├── churn_correlation.png
│   ├── confusion_matrix.png
│   ├── roc_curve.png
│   └── feature_importance.png
│
├── dashboard/
│   └── tableau_dashboard.png
│
└── README.md
```

## Setup
1. Data is located in the `data/` folder.
2. The analysis is performed in `notebooks/churn_analysis.ipynb`.
3. Model visualizations and results are stored in `outputs/`.
4. Dashboard mockups are in `dashboard/`.
